## 📌 Deskripsi Singkat

**WETON JOWO** adalah aplikasi web modern interaktif berbasis **Etnosains Titen Jawa** dan rujukan otentik **Kitab Primbon Betaljemur Adammakna**. Aplikasi ini memadukan warisan kebudayaan leluhur Nusantara dengan antarmuka digital modern yang intuitif, bebas iklan, serta terintegrasi langsung dengan waktu lokal perangkat pengguna (*Device Clock Sync*).

Aplikasi ini tidak sekadar menjadi ramalan, tetapi berfungsi sebagai **kompas navigasi spiritual, etika berikhtiar, serta penataan hari baik (petung hajat)** secara bijak dan rasional.

## ✨ Fitur-Fitur Unggulan

### 1. 🔮 Ramalan & Prediksi Harian Weton
* **Penyelarasan Jam Perangkat (*Device Clock Sync*)**: Perhitungan weton hari ini otomatis menyesuaikan jam & tanggal pada HP/komputer pengguna.
* **Indeks Harmoni Energi**: Menampilkan presentase potensi energi harian (Neptu Hening, Harmonis, atau Ekspansif).
* **Orientasi Rezeki & Naga Dina**: Menampilkan arah berkah utama untuk perjalanan hajat atau usaha.
* **Salin & Bagikan 1-Klik**: Rangkuman ramalan harian dapat langsung disalin ke media sosial atau pesan instan.

### 2. 🗓️ Kalkulator Weton & Neptu Presisi
* Perhitungan otomatis Hari (Saptawara) & Pasaran (Pancawara).
* Neptu dina, neptu pasaran, serta total neptu secara akurat.
* Konversi kalender Masehi ke sistem penanggalan Jawa secara mutlak.

### 3. 💍 Petung Salaki-Rabi (Kalkulator Jodoh & Pernikahan)
* Analisis tingkat keselarasan pasangan berbasis pembagi neptu (Ratu, Jodoh, Topo, Tinari, Padu, Sujanan, dll).
* Rekomendasi solusi syukuran/tumpengan untuk meminimalkan pantangan neptu.

### 4. 📜 Serat Pawukon (30 Wuku Lengkap)
* Ensiklopedia lengkap 30 Wuku (mulai dari Wuku Sinta hingga Wuku Watugunung).
* Menampilkan filosofi dewa naungan, pohon perlambangan, burung isyarat, serta wejangan kehati-hatian (*eling lan waspada*).

### 5. 🧭 Kompas Naga Dina & Arah Rezeki
* Panduan posisi Naga Hari untuk menghindari arah pantangan (*Naga Dina*).
* Rekomendasi arah harian untuk mencari rezeki, nego perniagaan, atau bepergian.

### 6. 📈 Pal Srigati & Prospek Rezeki 9 Siklus
* Prospek grafik fluktuasi rezeki usia 0–54+ tahun berbasis weton kelahiran.
* Skala angka keberuntungan (Skala 1–9) sebagai wawasan alokasi investasi dan ikhtiar hidup.

### 7. 👑 Satriya Jayabaya & Petung Watak Leluhur
* Perhitungan 7 kategori Satriya Jayabaya (Satriya Wibawa, Sumur Sinaba, Bumi Kapetak, dll).
* Menggambarkan karakter dasar, kelebihan, dan potensi kepemimpinan seseorang.

### 8. 🤲 Wirid & Doa Harian Weton
* Rekomendasi amalan wirid, zikir, dan doa keselamatan harian yang diselaraskan dengan weton hari berjalan.

### 9. 📖 Ensiklopedia Firasat & Glosarium Primbon
* Kamus istilah Primbon (Neptu, Wuku, Pasaran, Pancasuda, Geblak, dsb.).
* Firasat kedutan anggota tubuh dan maknanya menurut khazanah titen kuno.

## 🛠️ Cara Menjalankan di Komputer Lokal

### Prasyarat:
* [Node.js](https://nodejs.org/) v18.x atau lebih baru.
* NPM / PNPM / Yarn.

### Langkah-Langkah:

1. **Clone repository ini:**
   ```bash
   git clone https://github.com/username/weton-jowo.git
   cd weton-jowo
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Server Development:**
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:3000` (atau port yang disesuaikan Vite).

4. **Build untuk Produksi:**
   ```bash
   npm run build
   ```
   Hasil kompilasi siap publikasi akan tersimpan di direktori `dist/`.

## 🌐 Cara Deploy / Publish Gratis

### Option A: Vercel (Rekomendasi)
1. Push kode repository ini ke akun GitHub Anda.
2. Buka [Vercel.com](https://vercel.com) dan buat project baru.
3. Import repository **weton-jowo**.
4. Klik **Deploy**. Vercel akan otomatis mendeteksi Vite dan menyelesaikannya dalam <1 menit.

### Option B: Netlify
1. Buka [Netlify.com](https://netlify.com).
2. Pilih **"Add new site"** -> **"Import an existing project"**.
3. Hubungkan dengan GitHub dan pilih repo ini.
4. Set Build Command: `npm run build` dan Publish Directory: `dist`.
5. Klik **Deploy Site**.
